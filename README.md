# Автоматизированное тестирование поиска автобусных билетов

Проект содержит UI-автотесты для проверки работы поиска автобусных билетов на [RC](https://rc.gospodaprogrammisty.ru/).

Тесты написаны на Python с использованием **Playwright** и **Pytest**. Для организации кода применяется паттерн **Page Object Model (POM)**.

## Технологии

- Python 3.14
- Pytest — запуск и организация тестов
- Playwright — автоматизация браузера
- python-dotenv — работа с переменными окружения

## Структура проекта

```text
bus_playwright_test/
│
├── pages/                     # Page Object-классы
│   ├── __init__.py
│   ├── base_page.py           # Общие методы страниц
│   ├── bus_search_page.py     # Страница поиска автобусных билетов
│   ├── cart_page.py           # Страница корзины
│   └── login_page.py          # Страница авторизации
│
├── tests/                     # Автоматизированные тесты
│   ├── __init__.py
│   ├── test_auth.py           # Тесты авторизации
│   └── test_bus.py            # Тесты автобусного сервиса
│
├── conftest.py                # Фикстуры Pytest
├── pytest.ini                 # Настройки Pytest
├── .env                       # Переменные окружения (создаётся отдельно)
├── .gitignore                 # Исключения Git
└── README.md                  # Документация проекта
```

## Установка и настройка

### 1. Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
cd bus_playwright_test
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```powershell
.venv\Scripts\activate
```

### 3. Установка библиотек

```bash
pip install pytest playwright pytest-playwright python-dotenv
```

### 4. Установка браузера

Для запуска тестов необходимо установить браузер Chromium:

```bash
playwright install chromium
```

### 5. Настройка переменных окружения

Для работы тестов авторизации необходимо создать файл `.env` в корневой папке проекта.

В файле нужно указать свои корректные данные для входа на тестовый сайт:

```env
BUS_TEST_EMAIL=ваш_email
BUS_TEST_PASSWORD=ваш_пароль
```

**Важно:**

- Вместо примеров укажите собственный email и пароль от тестового аккаунта.
- Файл `.env` содержит конфиденциальные данные и не должен попадать в Git.
- Файл `.env` не хранится в репозитории, поэтому каждый пользователь проекта создаёт его самостоятельно.

### 6. Адрес тестового сайта

Адрес сайта для запуска тестов указан в файле `pytest.ini`:

```ini
[pytest]
base_url = https://rc.gospodaprogrammisty.ru/
```

При необходимости его можно заменить на другой адрес тестового стенда.

## Запуск тестов

Для запуска всех тестов выполните команду:

```bash
python -m pytest -v
```

Для запуска тестов только автобусного сервиса:

```bash
python -m pytest tests/test_bus.py -v
```

Для запуска тестов авторизации:

```bash
python -m pytest tests/test_auth.py -v
```

## Реализованные сценарии

### Автобусы

- Проверка открытия страницы поиска автобусных билетов.
- Проверка смены направлений городов.
- Проверка поиска билетов с пустыми полями.
- Проверка успешного поиска автобусных билетов.
- Проверка добавления билета в корзину.
- Проверка невозможности повторного добавления одного и того же билета.

### Авторизация

- Проверка успешной авторизации.
- Проверка ошибки при вводе неверного пароля.

## Page Object Model

В проекте используется паттерн Page Object Model (POM). Для каждой страницы или функциональной области сайта создан отдельный класс в папке `pages/`.

Каждый класс содержит:

- Локаторы элементов страницы.
- Методы взаимодействия с элементами.
- Методы проверки состояния страницы и результатов действий.

В тестах используются методы Page Object-классов, что позволяет не дублировать локаторы и логику взаимодействия с интерфейсом.

## Правила именования

Для поддержания единого стиля кода используются следующие правила:

- Названия файлов с тестами начинаются с `test_`.
- Названия тестовых функций начинаются с `test_`.
- Названия классов Page Object пишутся в формате `PascalCase`.
- Названия методов и переменных пишутся в формате `snake_case`.
- Локаторы хранятся внутри соответствующих Page Object-классов.
